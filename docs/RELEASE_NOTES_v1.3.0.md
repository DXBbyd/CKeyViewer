## ⚠️ 必须先看：以管理员身份运行

主程序**必须以管理员身份运行**，否则会弹出「请使用管理员运行此程序」然后直接退出。

这不是偷懒，是设计如此：按键状态用 `GetAsyncKeyState` 读取，**低完整性权限读不到更高级别进程的按键** —— 比如你以管理员身份启动的游戏，普通权限下覆盖层会完全没反应。

- 用**安装程序**装的：已经帮你把「以管理员身份运行此程序」兼容性标记写好了，双击快捷方式会自动弹 UAC。
- 用**便携版**的：右键 `CKeyViewer.exe` → 以管理员身份运行；或右键 → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」。

## 本次更新（1.2.0 → 1.3.0）

### 界面：开关与下拉菜单按 iOS 重写

- 修复**开关拨杆点击后不移动**的问题（旧模板在切换时没有重画拨杆位置）。
- 下拉菜单整体重做，不再用 WPF 默认的 `ComboBox` —— 它的默认模板在**深色主题下会渲染成「白底白字」**，几乎看不清；现在外观完全可控、深浅主题都正常。
- 设置面板继续沿用 iOS App Store 风格的**分组卡片 / 分段控件 / 圆角开关 / 底部说明文字**。

### 渲染：KPS / Total 数字不再被窗口裁掉

- **KPS / Total 条的文字现在会按可用宽度自动缩小字号**：以前数值一长（比如四位数 KPS、六位数 Total）就会被那小块窗口裁掉尾巴，现在会自适应到刚好放得下，任何数值都完整显示。

### 自检与工程整理

- 自检项扩充（菜单皮肤、下拉模板、布局几何等）。
- 新增/完善若干开发工具脚本（磁盘清理、日志残留清理等）。
- 加 `.gitattributes`，强制 `*.sh` 用 LF 换行，避免在 Windows 上 checkout 成 CRLF 导致脚本报错。

## 热键

| 热键 | 功能 |
| --- | --- |
| `Ctrl+Alt+K` / `F9` | 显示 / 隐藏覆盖层 |
| `Ctrl+Alt+R` / `F10` | 所有计数归零 |
| `Ctrl+Alt+N` / `F11` | 切到下一个档案 |
| `Ctrl+Alt+S` / `F12` | 打开设置面板 |
| `Ctrl+Alt+L` / `Ctrl+Alt+F8` | 进入 / 退出自由布局拖动模式（`Esc` 退出） |

## 配置文件

```
<exe 同级>/config/settings.json
<exe 同级>/config/profiles/<档案名>.json
```

格式与 JipperKeyViewer（原版游戏 Mod）**双向兼容**，原版的 `config` 目录可以直接拷过来用。
