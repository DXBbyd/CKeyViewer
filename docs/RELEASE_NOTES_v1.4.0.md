## ⚠️ 必须先看：以管理员身份运行

主程序**必须以管理员身份运行**，否则会弹出「请使用管理员运行此程序」然后直接退出。

按键状态用 `GetAsyncKeyState` 读取，**低完整性权限读不到更高级别进程的按键** —— 比如你以管理员身份启动的游戏，普通权限下覆盖层会完全没反应。

- 用**安装程序**装的：已自动写好「以管理员身份运行此程序」标记，双击快捷方式即弹 UAC。
- 用**便携版**的：右键 → 以管理员身份运行；或右键 → 属性 → 兼容性 → 勾选该项。

## 本次更新（1.3.0 → 1.4.0）

### 1. 修复：补上信息层「视觉进度条」

1.3.0 的信息层里 `PROG` 只有一串百分比文字，**并没有画进度条** —— 这一版把它补上了：
`PROG` 元素下方会画一条**圆角进度条**，按游戏当前进度实时填充。可以在「ADOFAI」页单独开关，颜色 / 轨道底色都能改。

### 2. 预设布局现在可以全屏自由拖动

- 非自由布局下，**按住热键（默认 `Alt`）再用鼠标左键拖动覆盖层**，就能把整套键位放到屏幕任意位置，松手自动保存。
- 从九宫格吸附位置拖出来会自动解除吸附、改走自定义位置。
- 拖动热键可在「吸附」页改（任意键）或关掉。
- 「拖拽为只」等原有自由布局编辑不受影响。

### 3. 新增「吸附到 ADOFAI 游戏窗口」（带动画）

- 打开后，**按键覆盖层与信息层都会贴着游戏窗口摆**；游戏窗口移动 / 缩放的，覆盖层会**平滑缓动跟着走**，不用手动摆。
- 自动检测游戏窗口（默认按标题 "A Dance of Fire and Ice" 匹配，找不到时退回 Unity 窗口类，兼容不同语言版本）。
- 游戏没运行时自动退回普通工作区吸附，不影响使用。
- 按键贴游戏窗口的哪个角由「吸附」页的九宫格决定。

### 4. 信息层可切换「布局预设」

信息层的自动排列新增 6 种可一键切换的预设：**堆叠（竖排）/ 顶栏（横排）/ 底栏（横排）/ 左侧栏 / 右侧栏 / 精简**。
进度条在内的所有元素会跟着预设一起重排；「精简」只保留 `Combo / ACC / X-ACC / PROG` 几行，播报更干净。

### 5. 设置界面更多动画

- 切换标签页时，内容从「整页淡入」升级为**各组卡片错峰淡入 + 轻微上滑**，层次更顺。
- 窗口每次打开有出场动画；勾选框切换时有一点轻微回弹反馈。
- 新增的分段控件（如布局预设）带滑动的高亮块。

### 其它

- 自检项扩充到 111 项（新增信息层进度条开 / 关的高度校验）。

## 兼容性

- 配置格式与 1.3.0 / JipperKeyViewer **完全兼容**，旧 `config/` 可直接沿用，无需迁移。
- 新增的「吸附游戏窗口」「布局预设」等开关存在 `config/adofai.json`，「拖动热键」存在 `config/settings.json`，**不会破坏与 jipper 原版配置的双向互读**。

## 热键

| 热键 | 功能 |
| --- | --- |
| `Ctrl+Alt+K` / `F9` | 显示 / 隐藏覆盖层 |
| `Ctrl+Alt+R` / `F10` | 所有计数归零 |
| `Ctrl+Alt+N` / `F11` | 切到下一个档案 |
| `Ctrl+Alt+S` / `F12` | 打开设置面板 |
| `Ctrl+Alt+L` / `Ctrl+Alt+F8` | 进入 / 退出自由布局拖动模式（`Esc` 退出） |
| `Alt` + 拖左键 | 拖动整套预设覆盖层（可在「吸附」页改键） |
