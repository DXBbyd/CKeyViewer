## ⚠️ 必须先看：以管理员身份运行

主程序**必须以管理员身份运行**，否则会弹出「请使用管理员运行此程序」然后直接退出。

按键状态用 `GetAsyncKeyState` 读取，**低完整性权限读不到更高级别进程的按键** —— 比如你以管理员身份启动的游戏，普通权限下覆盖层会完全没反应。

- 用**安装程序**装的：已自动写好「以管理员身份运行此程序」标记，双击快捷方式即弹 UAC。
- 用**便携版**的：右键 → 以管理员身份运行；或右键 → 属性 → 兼容性 → 勾选该项。

## 本次更新（1.3.0 → 1.4.0）

### 1. 修复：补上信息层「视觉进度条」

1.3.0 的信息层里 `PROG` 只有一串百分比文字，**并没有画进度条** —— 这一版把它补上了：
`PROG` 元素下方会画一条**圆角进度条**，按游戏当前进度实时填充。可以在「ADOFAI」页单独开关，颜色 / 轨道底色都能改。

### 2. 预设布局现在可以全屏自由拖动

- 非自由布局下，**按住热键（默认 `Alt`）再用鼠标左键拖动覆盖层**，就能把整套键位放到屏幕任意位置，松手自动保存。
- 从九宫格吸附位置拖出来会自动解除吸附、改走自定义位置。
- 拖动热键可在「吸附」页改（任意键）或关掉。
- 「拖拽为只」等原有自由布局编辑不受影响。

### 3. 新增「吸附到 ADOFAI 游戏窗口」（带动画）

- 打开后，**按键覆盖层与信息层都会贴着游戏窗口摆**；游戏窗口移动 / 缩放的，覆盖层会**平滑缓动跟着走**，不用手动摆。
- 自动检测游戏窗口（默认按标题 "A Dance of Fire and Ice" 匹配，找不到时退回 Unity 窗口类，兼容不同语言版本）。
- 游戏没运行时自动退回普通工作区吸附，不影响使用。
- 按键贴游戏窗口的哪个角由「吸附」页的九宫格决定。

### 4. 信息层可切换「布局预设」

信息层的自动排列新增 6 种可一键切换的预设：**堆叠（竖排）/ 顶栏（横排）/ 底栏（横排）/ 左侧栏 / 右侧栏 / 精简**。
进度条在内的所有元素会跟着预设一起重排；「精简」只保留 `Combo / ACC / X-ACC / PROG` 几行，播报更干净。

### 5. 设置界面更多动画

- 切换标签页时，内容从「整页淡入」升级为**各组卡片错峰淡入 + 轻微上滑**，层次更顺。
- 窗口每次打开有出场动画；勾选框切换时有一点轻微回弹反馈。
- 新增的分段控件（如布局预设）带滑动的高亮块。

### 6. 修复：一串「看着像坏了但没报错」的问题

都是同一类毛病 —— 失败时**什么都不说**，用户只能靠猜。

- **流媒体模式下 KPS / 总数变成两条空的紫色横条**：原版是把这个元素整个关掉（背景 + 描边一起消失），
  我们之前只跳过了文字，于是留下两条空心条。现在整条不画，并在「统计」页给出一句提示 + 一键关闭流媒体模式。
- **「选了右下角，按键却停在别处」**：「吸附」页的九宫格只有一个，但它管的字段有两个
  （贴工作区 / 贴游戏窗口）。现在按**当前真正生效**的那个判断，并且两个字段一起写；
  页面下方新增一行实时状态，直接告诉你游戏窗口找到没有、找的是哪一个。
- **改一个选项设置页就跳回顶部**：页面里几百个控件的回调都走「就地重建」，
  而它的默认值是「回到顶部」。现在默认保持滚动位置，只有切标签页才回顶。
- **信息层跟随比按键层卡**：这两层跑在同一个 8ms 定时器上，差别在于信息层每帧都在
  `Invalidate()` —— 一块 1920×1080 的面重排一次要 3.5ms，占了 8ms 预算的 44%，
  而成本来自**排版不是像素**（缩到 564×422 还是 3.41ms）。现在只在尺寸真变化时才重绘，
  缓动也改成按帧间隔算（`1-exp(-dt/τ)`），掉帧时不会再一跳一跳。
- **游戏全屏后按键还贴在全屏之前那个角**：游戏窗口一旦认不出来，跟随就直接
  `return`，覆盖层会**冻在**上一次的位置。现在会（宽限 0.6 秒后）立刻退回普通吸附，
  不会卡住 —— 那 0.6 秒是留给切全屏的：Alt+Enter 的一瞬间窗口会短暂变成「图标化」，
  立刻退回会让覆盖层闪一下再跳回来。
  识别窗口也重写了，按 **进程归属 → Unity 窗口类 → 标题 → 面积** 判定，
  滤掉最小化窗口（它的坐标是 -32000）和 1×1 / 1905×4 这类没意义的系统辅助窗口；
  并且**去掉了「只按窗口类兜底」那条路** —— 你机器上的别的 Unity 游戏
  （Hollow Knight、Rhythm Doctor 之类）以前可能被误认成 ADOFAI。
- **ADOFAI 信息层一直「连接失败」**：游戏退出后经常留下一个**同名的 32KB 残留进程**
  （状态 Unknown、用户 N/A），原来的代码只取进程列表里的第一个 —— 撞上它就永远连不上，
  而且报错还会误导成「请以管理员运行」。现在逐个进程试、用「有没有 mono 运行时」判定真假，
  并把每个进程的失败原因分别列出来。启动日志里也会记下进程列表与自己的提权状态。
- **设置页提示里的 `**` 加粗标记被原样画出来**：说明文字现在真的支持加粗了。

新增命令行诊断（不用装任何东西，也不写游戏目录）：

```
CKeyViewer.exe --winprobe [输出文件]
```

开着游戏跑一次，会把「有几个 ADOFAI 进程、每个是否还活着、窗口枚举结果、
最后判定成哪个窗口 / 为什么没判定出来」全部打出来，用来定位「为什么没吸附」。

### 其它

- 自检项扩充到 **125 项**（新增游戏窗口挑选的 9 项：UMM 改标题、过小窗口、别的 Unity 游戏
  不误认、最小化窗口、无进程 / 无窗口的原因文案、自己进程的窗口不认、同级取面积最大等）。

## 兼容性

- 配置格式与 1.3.0 / JipperKeyViewer **完全兼容**，旧 `config/` 可直接沿用，无需迁移。
- 新增的「吸附游戏窗口」「布局预设」等开关存在 `config/adofai.json`，「拖动热键」存在 `config/settings.json`，**不会破坏与 jipper 原版配置的双向互读**。

## 热键

| 热键 | 功能 |
| --- | --- |
| `Ctrl+Alt+K` / `F9` | 显示 / 隐藏覆盖层 |
| `Ctrl+Alt+R` / `F10` | 所有计数归零 |
| `Ctrl+Alt+N` / `F11` | 切到下一个档案 |
| `Ctrl+Alt+S` / `F12` | 打开设置面板 |
| `Ctrl+Alt+L` / `Ctrl+Alt+F8` | 进入 / 退出自由布局拖动模式（`Esc` 退出） |
| `Alt` + 拖左键 | 拖动整套预设覆盖层（可在「吸附」页改键） |
