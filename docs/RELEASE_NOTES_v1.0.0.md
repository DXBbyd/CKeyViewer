Windows 上的**按键可视化覆盖层** —— 透明置顶窗口，实时显示每个按键的按下状态、按键计数、KPS 与「雨线」特效。

配置格式与 [JipperKeyViewer](https://github.com/adofaiex/JipperKeyViewer)（原版是 Unity 游戏 Mod）**双向兼容**：原版的 `config` 目录可以直接拷过来用，改完也能拿回去。

## ⚠️ 必须先看：以管理员身份运行

主程序**必须以管理员身份运行**，否则会弹出「请使用管理员运行此程序」然后直接退出。

这不是偷懒，是设计如此：按键状态用 `GetAsyncKeyState` 读取，**低完整性权限读不到更高级别进程的按键** —— 比如你以管理员身份启动的游戏，普通权限下覆盖层会完全没反应。

- 用**安装程序**装的：已经帮你把「以管理员身份运行此程序」兼容性标记写好了，双击快捷方式会自动弹 UAC，不用每次右键。
- 用**便携版**的：右键 `CKeyViewer.exe` → 以管理员身份运行；或者右键 → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」。

**双击没反应？** 见 [README 的「装不上 / 打不开？」](https://github.com/DXBbyd/CKeyViewer#装不上--打不开) 一节。
最常见的原因是所在目录被执行策略限制（退出码 `0x800080A0`），把 exe 拷到普通目录再运行即可。

## 这个版本有什么

### 键盘与布局

- 主键 **8 种预设布局**（Key8 / 10 / 12 / 14 / 16 / 20 / 24 / Full108 全键盘）+ 脚键 **8 种**（2 ~ 16 键）
- **可绑定任意按键**：字母 / 数字 / 功能键 / 小键盘，以及**左右区分的 Shift / Ctrl / Alt** 和**鼠标左中右 + 两个侧键**
- **自由布局**：每个元素是一个可拖拽节点，位置 / 尺寸 / 层级 / 配色 / 按键绑定全可调，支持图层组与图片节点
- 按 `Ctrl+Alt+L` 可以直接在覆盖层上拖动摆放，`Esc` 退出并保存

### 视觉

- **配色**：全局配色（常态 / 按下）+ **42 个槽位的每键配色** + Full108 统一配色，均含背景 / 描边 / 文字
- **雨线**：三行独立的速度 / 高度 / 宽度 / 起始 Y，渐变色与淡出，描边与阴影；另有**鬼键雨线**
- **按压缩放**：按下缩到指定倍数、松开弹回，**27 条缓动曲线**逐条对齐原版
- **文字**：字号、字体（含原版的 OTF 支持）、描边、阴影、计数格式化、流媒体模式

### 统计与操作

- **KPS** 实时速率、**Total** 累计总数、**每键点击次数**，支持居中 / 堆叠 / 独立位置
- **12 页深色设置面板**（含「关于」），所有改动即时生效 + 600 ms 防抖落盘
- 系统托盘图标 + 菜单，**5 组全局热键**（每组带备选键，撞车时自动退档）
- 覆盖层完全鼠标穿透、不抢焦点、不进任务栏与 Alt+Tab

### 实现方式

- 独立进程，**`GetAsyncKeyState` 8 ms 轮询**读取按键，不用键盘钩子 —— 不拖慢前台程序，也不受输入法 / 游戏独占模式影响
- 完全静止时降到 0.5 s 一帧，待机几乎不占 CPU
- 附带 `CKeyViewer.exe --selftest` 无界面自检（20 项断言，覆盖修饰键与鼠标键）

## 首次发布说明

这是 **1.0.0**，第一个公开版本。

- 只在 **Windows 10 / 11 x64** 上验证过。
- 自由布局的**图片 / 视频节点**（`NodeType = 3`）代码路径已就绪，但尚未做真机贴图回归。
- 鬼键雨线的代码路径已就绪，但默认配置里 `GhostKey*` 全为 0，需要先在「按键绑定」页绑定鬼键才能看到效果。
- 安装程序**同时只支持一份安装**：卸载信息与快捷方式用的是固定名字，在第二个目录上跑卸载会清掉第一份的快捷方式与「应用」列表项（安装目录本身不受影响）。
- 高 DPI 依赖 `PerMonitorV2`，跨屏移动时的重新布局未做实测。
