# CKeyViewer 1.1.0

Windows 上的按键可视化覆盖层（JipperKeyViewer 的独立实现，与原版作者无隶属关系）。

## 新增

- **自定义字体**：每个按键节点可单独指定字体；全局也可统一指定，覆盖层文字用你选的字体渲染。
- **引导式创建按键**：点「＋ 按键」后进入三步引导 —— ① 录入按键 ② 配置尺寸 ③ 仅拖拽定位（点完「完成引导」才落盘），不再需要手动敲 KeyCode。
- **编辑器内直接切换按键**：自定义布局里选中某个按键后，不用先关掉编辑窗口就能切到另一个按键继续改。
- **覆盖层背景图片**：支持把一张图片作为覆盖层背景，可整屏铺满（cover）/ 等比缩放（contain）/ 拉伸（stretch），带可选边框与透明度。
- **界面更有动感**：按钮悬停/按下有缩放反馈，切换标签页时设置面板淡入+位移。

## 修复与改动

- 拖拽为只：新增「拖拽为只」开关，开启后位置只用拖动设置，隐藏 X/Y 数字框，避免误改。
- 打包产物版本号统一到 1.1.0（主程序 + 安装程序 + 便携 zip + SHA256SUMS）。

## 下载

- `CKeyViewerSetup-1.1.0.exe` —— 安装版（推荐），自动打「以管理员运行」标记。
- `CKeyViewer-1.1.0-portable-win64.zip` —— 便携版，解压即用，自带 .NET 运行时。

> **必须以管理员身份运行**：否则读不到以管理员启动的游戏的按键。
