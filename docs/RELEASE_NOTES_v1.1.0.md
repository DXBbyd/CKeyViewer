## ⚠️ 必须先看：以管理员身份运行

主程序**必须以管理员身份运行**，否则会弹出「请使用管理员运行此程序」然后直接退出。

这不是偷懒，是设计如此：按键状态用 `GetAsyncKeyState` 读取，**低完整性权限读不到更高级别进程的按键** —— 比如你以管理员身份启动的游戏，普通权限下覆盖层会完全没反应。

- 用**安装程序**装的：已经帮你把「以管理员身份运行此程序」兼容性标记写好了，双击快捷方式会自动弹 UAC，不用每次右键。
- 用**便携版**的：右键 `CKeyViewer.exe` → 以管理员身份运行；或者右键 → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」。

**双击没反应？** 见 [README 的「装不上 / 打不开？」](https://github.com/DXBbyd/CKeyViewer#装不上--打不开) 一节。
最常见的原因是所在目录被执行策略限制（退出码 `0x800080A0`），把 exe 拷到普通目录再运行即可。

## 这个版本有什么

### 冰与火之舞（ADOFAI）实时信息覆盖层 —— 不用装 Mod

在按键覆盖层之上再叠一层 ADOFAI 的实时数据，效果对标 **JipperOverlayer**，
但**不需要安装任何 Mod、不需要 UMM / MelonLoader，游戏目录不会被写入任何文件**。

显示内容（每一项都能单独开关）：**Combo** / 状态标题（`PERFECT PLAY` / `PERFECTIONIST` / `AUTO-TILE`）/
**准确率 ACC** / **X-精准度 X-ACC** / **进度 PROG** / **BPM** / **判定分布** / **Deaths · CP · Try**。

**原理**：JipperOverlayer 是游戏内的 UMM Mod，靠 Harmony 在游戏进程**内部**反射取值。
本项目跨进程直接调用游戏自带的 **Mono 运行时公开 C API**（`mono_class_from_name` /
`mono_field_get_offset` / `mono_field_static_get_value` …），全部是 Mono 对外承诺、多年稳定的 ABI，
不依赖逆向出来的内部结构体偏移。做法是 `VirtualAllocEx` → 写一段 shellcode → `CreateRemoteThread`
让游戏自己执行 → `ReadProcessMemory` 取结果。

- 游戏里**没有 combo 字段**，连击是按判定序列自己算的（原版也一样）。
- 尝试次数游戏也没这字段，用 `deaths + 1` 表示。
- 信息层是**铺满工作区的独立窗口**，所以每个元素都能拖到屏幕任意位置，
  不会被那小块键帽窗口框住。**第一次拖动会自动退出自动排列**，拖走「判定分布」不会带着整列一起动。
- JipperOverlayer 的 `LabelConfig` 九个标签文案也搬过来了，可逐条改、一键恢复默认。

### 界面换成 iPhone App Store 风格

设置面板与安装程序都重做成 iOS 的观感：左侧标签栏 + 右侧成组卡片、圆角开关、分段控件、
底部说明文字。**「外观」页可切浅色 / 深色**，切完整个面板立刻重建。

- 设置面板扩到 **14 个标签页**（新增「吸附」，含「关于」）。
- 托盘菜单同一套外观：圆角卡片、悬停整行铺强调色淡底、勾选是强调色对勾、危险项红字。
  菜单配色跟着主题走，面板里刚从深色切浅色，下次弹出就是浅色。
- 所有按钮 / 开关都有悬停与按下的反馈，开关滑动是带缓动的动画。

### 新增「吸附」页 + 动态吸附

- **九宫格锚点**：左上 / 中上 / 右上 / 左中 / 正中 / 右中 / 左下 / 中下 / 右下，外加第 10 个选项「自由摆放」。
- **离边缘的边距**（0–160）。
- **动态吸附**：勾上之后，窗口 / 分辨率 / 任务栏 / DPI 缩放一变就自动重新吸到新位置。

三条硬约束：

1. **只改位置，绝不改大小。**
2. **对着「工作区」吸附**（屏幕减掉任务栏），所以吸到「左下」不会压在任务栏图标上；副屏在左边也能算对。
3. 动态吸附是**每帧重新读工作区**，而不是只听 `DisplaySettingsChanged` 事件 ——
   那个事件在「只改任务栏高度」「拖到另一块 DPI 不同的屏」时会漏。

托盘菜单里也加了「吸附位置」子菜单，不用开设置面板就能切。

### 键盘与布局

- 主键 **8 种预设布局**（Key8 / 10 / 12 / 14 / 16 / 20 / 24 / Full108 全键盘）+ 脚键 **8 种**（2 ~ 16 键）
- **可绑定任意按键**：字母 / 数字 / 功能键 / 小键盘，以及**左右区分的 Shift / Ctrl / Alt** 和**鼠标左中右 + 两个侧键**
- **自由布局**：每个元素是一个可拖拽节点，位置 / 尺寸 / 层级 / 配色 / 按键绑定全可调，支持图层组与图片节点
- 按 `Ctrl+Alt+L` 可以直接在覆盖层上拖动摆放，`Esc` 退出并保存
- **自定义字体**：每个按键节点可单独指定字体，全局也可统一指定
- **引导式创建按键**：点「＋ 按键」后三步引导 —— ① 录入按键 ② 配置尺寸 ③ 仅拖拽定位
- **覆盖层背景图片**：可整屏铺满 / 等比缩放 / 拉伸，带可选边框与透明度

### 视觉

- **配色**：全局配色（常态 / 按下）+ **42 个槽位的每键配色** + Full108 统一配色，均含背景 / 描边 / 文字
- **雨线**：三行独立的速度 / 高度 / 宽度 / 起始 Y，渐变色与淡出，描边与阴影；另有**鬼键雨线**
- **按压缩放**：按下缩到指定倍数、松开弹回，**27 条缓动曲线**逐条对齐原版
- **文字**：字号、字体（含原版的 OTF 支持）、描边、阴影、计数格式化、流媒体模式

### 统计与操作

- **KPS** 实时速率、**Total** 累计总数、**每键点击次数**，支持居中 / 堆叠 / 独立位置
- 所有改动即时生效 + 600 ms 防抖落盘
- 系统托盘图标 + 菜单，**5 组全局热键**（每组带备选键，撞车时自动退档）
- 覆盖层完全鼠标穿透、不抢焦点、不进任务栏与 Alt+Tab

### 实现方式

- 独立进程，**`GetAsyncKeyState` 8 ms 轮询**读取按键，不用键盘钩子 —— 不拖慢前台程序，也不受输入法 / 游戏独占模式影响
- 完全静止时降到 0.5 s 一帧，待机几乎不占 CPU
- 附带 `CKeyViewer.exe --selftest` 无界面自检（**90 项断言**，覆盖按键捕获 / 吸附几何 / 信息层元素布局 / 菜单皮肤）

## 首次使用提示

- 启动后**没有窗口**：程序以托盘图标 + 全屏透明覆盖层的形式存在。
  如果看不到覆盖层，检查托盘（Win11 默认收进「隐藏的图标」折叠区，点 `^` 展开）。
- 全局热键：`Ctrl+Alt+K` 显示 / 隐藏，`Ctrl+Alt+R` 计数归零，`Ctrl+Alt+N` 下一个档案，
  `Ctrl+Alt+S` 设置面板，`Ctrl+Alt+L` 布局模式。
- 配置文件在 `<exe 同级>/config/`，格式与 JipperKeyViewer **双向兼容**，原版的 `config` 目录可直接拷过来。
- ADOFAI 覆盖层要先启用（托盘菜单或设置面板的「ADOFAI」页），**进入关卡后**数字才会出现。

## 已知限制

- 只在 **Windows 10 / 11 x64** 上验证过。高 DPI 依赖 `PerMonitorV2`，跨屏移动时的重新布局未做实测。
- 必须以管理员身份运行（见上），这是设计如此，不是缺陷。
- ADOFAI 的**真实演奏中**的连击数与判定分布尚未实测（连接、字段偏移、准确率交叉验证都已通过）。
- 原版 `DisplayElement` 一共 22 项，本实现覆盖了上面那 8 类；`MusicTime` / `MapTime` / `Best` /
  `TimingScale` / `FPS` / `Author` / `Start` / `Timing` / `AvgTiming` / `XScore` / `Potential*`
  的游戏字段还没逐个验证，宁可不显示也不显示错数。
- 自由布局的**图片 / 视频节点**（`NodeType = 3`）代码路径已就绪，但尚未做真机贴图回归。
- 鬼键雨线的代码路径已就绪，但默认配置里 `GhostKey*` 全为 0，需要先在「按键绑定」页绑定鬼键才能看到效果。
- 安装程序**同时只支持一份安装**：卸载信息与快捷方式用的是固定名字，
  在第二个目录上跑一次卸载会把第一份的快捷方式与「应用」列表项一并清掉（安装目录本身不受影响）。
- 托盘右键菜单为了圆角卡片的效果关掉了系统投影，只留 1px 描边；纯白桌面上的层次感比原生菜单弱一些。
